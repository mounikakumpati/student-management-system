# Student Management System - Java

A simple console-based Java project to manage student records using OOP concepts and ArrayList.

### 🚀 Features
- Add Student (ID, Name, Marks)
- View All Students
- Search Student by ID
- Delete Student by ID

### 🛠️ Technologies Used
- Java, OOP, ArrayList, Scanner Class

### ▶️ How to Run
javac StudentManagement.java
java StudentManagement
